# Security Policy for Arachne

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or SSRF bypass within Arachne, please report it privately:

1. **Email**: security@arachne-crawler.org
2. **Details to include**:
   - Description of the issue & severity.
   - Proof-of-concept steps or payload.
   - Target component (Worker, Coordinator, CLI, Core).

We prioritize security issues and will respond within 48 hours.
